# IEEE NMAMIT Student Branch Website

## Tech Stack
- React 18
- Vite
- Tailwind CSS (v3.4)
- React Router v6
- Lucide React

## How to Run
1. `npm install`
2. `npm run dev`

## Ownership Table
| Feature | Owner |
|---------|-------|
| Base, Routing, CSS Utilities | Dev A |
| Navbar, Hero | Dev A |
| Intro, FeaturedEvents, Cards | Dev B |
| JoinCTA, Footer, Data files | Dev B |

## Branch Workflow
- `main` is stable.
- Create feature branches: `feat/feature-name`
- Merge via Pull Request. Do not overwrite base configurations (Tailwind, routing) if not owned.
